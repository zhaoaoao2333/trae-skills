## 一、居民端小程序

---

### A1 用户体系 | 高优

| 字段 | 内容 |
|------|------|
| 目的 | 居民身份认证与基础信息管理 |
| 信息架构 | 用户ID、微信手机号、头像、昵称 |
| 内容来源 | 微信授权获取手机号；头像昵称用户自行设置 |
| 操作 | 微信授权登录、编辑个人资料、设置头像昵称 |
| 业务规则 | 允许游客模式浏览（不登录可见部分内容）；必须登录才能下单/发帖/提问；不支持账号注销 |
| 关联模块 | 全部模块（登录后可用） |
| 待确认项 | — |

#### 收货地址

| 字段 | 内容 |
|------|------|
| 目的 | 管理收货地址，用于团购下单 |
| 信息架构 | 联系人、手机号、省市区、详细地址、是否默认地址 |
| 内容来源 | 用户手动输入 |
| 操作 | 新增/编辑/删除地址、设为默认地址 |
| 业务规则 | 地址数量不设上限；一笔订单只支持一个收货地址；至少一个默认地址 |
| 关联模块 | A2 团购下单 |

---

### A2 团购板块 | 高优

| 字段 | 内容 |
|------|------|
| 目的 | 居民通过团长购买商品，团长分佣 |
| 信息架构 | 团长列表 → 团长主页（个人主页、公告栏、商品分类列表、最近订单【脱敏】、评价数据）→ 商品详情（商品名、图片、原价、折扣价、库存、销量） |
| 内容来源 | 商品由供货商PC端挂靠，团长主页内容由团长编辑 |
| 操作 | 浏览团长 → 进入团长主页 → 按分类/排序筛选商品 → 搜索商品（仅当前团长名下）→ 加入购物车 → 下单（选地址+备注）→ 微信支付 |
| 业务规则 | 先选团长再看商品（不可直接看全平台商品比价）；排序：价格/销量/最新；下单时校验库存，提交订单后占用库存；支付超时15分钟自动取消，库存释放；团长主页支持分享（主页/单个商品链接） |
| 关联模块 | A1 用户、A6 订单、A7 消息、A8 评价 |
| 待确认项 | — |

---

### A3 周边商家 | 高优

| 字段 | 内容 |
|------|------|
| 目的 | 居民查看附近门店，线上下单到店自提 |
| 信息架构 | 附近门店列表（店名、距离【直线距离】、地址、商品列表）→ 商品详情 → 数字码（手机号后四位，支付后生成）|
| 内容来源 | 门店和商品由供货商PC端管理 |
| 操作 | 按距离排序浏览附近门店 → 按商品分类筛选门店 → 下单（选商品+备注）→ 微信支付 → 查看数字码 → 到店取货手动完成 |
| 业务规则 | 距离为直线距离；仅支持自提；数字码=手机号后四位，不设有效期；供货商备货完成后7天自动完成；取货后不可退款；备货超时不做自动退款；支付超时15分钟 |
| 关联模块 | A1 用户、A6 订单、A7 消息 |

---

### A4 社区论坛 | 中优

| 字段 | 内容 |
|------|------|
| 目的 | 社区居民交流互动 |
| 信息架构 | 帖子（标题、正文、图片【最多9张】、视频【最大100MB】、发布人、时间、分类）、评论（多层嵌套）、点赞数、收藏数 |
| 内容来源 | 用户发布 + 敏感词检测 |
| 操作 | 发布帖子（文字/图片/视频）、点赞、评论（多层嵌套）、收藏、举报、删除自己的帖子/评论、关注其他用户 |
| 业务规则 | 无需审核，发帖后立即显示；平台预设分类；论坛顶部Tab：推荐（全部）/ 关注；支持关注其他用户，查看关注动态；举报由平台审核后处理；平台可删除帖子/封禁用户 |
| 关联模块 | A1 用户、A7 消息 |

---

### A5 知识问答 | 中优

| 字段 | 内容 |
|------|------|
| 目的 | 居民提问，其他人回答，提问者可打赏 |
| 信息架构 | 问题（标题【有字数限制】、正文【无限制】、分类【单选】、提问人、时间、状态）、回答（正文【无限制】、点赞数、打赏数）|
| 内容来源 | 用户发布 + 敏感词检测；分类由平台预设 |
| 操作 | 提问、回答（仅点赞+打赏）、下架问题、打赏（平台设区间，提问者选择金额） |
| 业务规则 | 无需审核；答案对其他居民完全隐藏（仅提问者可见）；不区分最佳答案；打赏到平台账户，用户申请提现，线下打款；可给多个回答者打赏；下架后打赏不退回；无有效期，手动下架；可编辑问题 |
| 关联模块 | A1 用户、A7 消息、A9 个人中心（提现） |

---

### A6 订单管理 | 高优

| 字段 | 内容 |
|------|------|
| 目的 | 统一管理团购和周边商家订单 |
| 信息架构 | 团购订单：订单号、商品、金额、团长、收货地址、状态；周边商家订单：订单号、商品、金额、门店、数字码、状态 |
| 内容来源 | 系统生成 |
| 操作 | 查看订单列表（分Tab）、按状态筛选、查看订单详情、确认收货（团购）/完成取货（周边商家）、申请退款 |
| 业务规则 | 团购和周边订单分开管理；团购状态：待支付→待发货→待收货→已完成；周边状态：待支付→备货中→待取货→已完成；团购7天自动收货；周边备货完成7天自动完成 |

#### 退款

| 字段 | 内容 |
|------|------|
| 目的 | 退款申请与进度跟踪 |
| 信息架构 | 退款详情页（退款金额、原因、状态：退款中/已退款/退款驳回） |
| 操作 | 申请退款（选择原因）、查看退款进度 |
| 业务规则 | 团购：居民发起，供货商处理，1天不处理自动同意，支持部分退款，退款金额系统自动算，钱款原路退回；周边：未取货可退款，取货后不可退；退款被拒提示联系平台 |

## 三、PC管理端（功能清单，不细化）

### 供货商端

| 模块 | 功能 |
|------|------|
| 商品管理 | 新增/编辑/上下架商品、设置库存、团购商品和周边商品两套独立库 |
| 团购挂靠 | 手动将商品挂靠到团长，设置各团长折扣价 |
| 门店管理 | 编辑门店信息（店名、地址、定位、商品列表） |
| 订单处理 | 团购发货、周边商家备货、订单状态管理 |
| 退款处理 | 审核退款（同意/驳回），支持部分退款 |

### 平台管理员端

| 模块 | 功能 |
|------|------|
| 用户管理 | 管理居民/团长账号，封禁/解封 |
| 团长审核 | 审核团长申请（通过/驳回） |
| 分佣设置 | 设置团长分佣比例 |
| 内容审核 | 帖子/评论审核、举报处理、敏感词管理 |
| 分类管理 | 预设论坛和问答分类 |
| 打赏设置 | 设置问答打赏金额区间 |
| 提现审核 | 审核团长收益提现、问答打赏提现 |
