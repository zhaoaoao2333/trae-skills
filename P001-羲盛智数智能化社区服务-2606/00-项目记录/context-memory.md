## 经验教训

### [2026-06-11] HTML原型生成必须自检清单

**问题**：子Agent生成的居民端原型HTML文件中，body内存在：
- 重复的 `<style>` CSS块
- 全部JavaScript代码裸露在 `<script>` 标签外部（约308行），导致页面显示源代码文字

**根因**：派发子Agent生成HTML后，主Agent未做**产出物结构完整性校验**就直接交付。

**修复**：删除body内的重复CSS块和裸露JS代码，从991行精简到683行。

**后续规则**：任何HTML/代码类产出物生成后，主Agent必须执行以下自检，通过后才能交付：
1. 检查 `<script>` 标签是否正常包裹所有JS代码，有无裸露代码
2. 检查是否有重复的 `<style>` / `<script>` 块
3. 检查关键函数（navTo、goBack、showToast、switchTab）是否仅定义一次
4. 检查核心DOM元素（navBar、tabBar、toast、modalOverlay）是否存在
5. 浏览器实机预览确认无白屏/乱码/控制台报错
