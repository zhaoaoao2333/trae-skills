# 业务流程梳理 v1.0

**日期**: 2026-06-11  
**项目**: P001-羲盛智数智能化社区服务

---

## 一、端口与角色

### 端口
| 端口 | 说明 |
|------|------|
| 居民端微信小程序 | 面向社区居民 |
| 团长端微信小程序 | 面向团长 |
| PC管理后台 | 平台管理员+供货商（原型不生成） |

### 角色
| 角色 | 端口 | 核心诉求 |
|------|------|---------|
| 居民 | 居民端小程序 | 团购下单、到店购物、社区交流、知识问答 |
| 团长 | 团长端小程序 | 管理商品、查看订单、分享商品、查看收益 |
| 供货商 | PC后台 | 管理商品、设置折扣、管理门店、发货、处理退款 |
| 平台管理员 | PC后台 | 管理团长/供货商、设置分佣、内容审核、平台运营 |

### 关键规则
- 团长和居民身份**互斥**（一人不能同时拥有两种身份）
- 居民端有申请团长入口 → 平台审核 → 通过后成为团长，此后只能使用团长端
- 团长**不绑定社区**，更像带货达人，分享商品链接给居民，居民下单后团长等分佣

## 二、团购板块 — 主流程

### 商品挂靠
1. 供货商在PC管理端手动将商品挂靠到多个团长
2. 同一商品可挂靠多个团长，每个团长可设置不同折扣价
3. 团长有个人主页，展示该团长全部商品，可分享主页或单个商品链接

### 用户下单
1. 居民在居民端小程序浏览商品（也可通过团长分享链接进入）
2. 选择团长 → 选择商品 → 加入购物车（支持多商品）
3. 确认订单：选择收货地址（支持默认地址，一笔订单一个地址）
4. 微信支付 → 支付成功 → 订单生成

### 订单状态
```
待支付 → 已支付 → 待发货 → 已发货 → 已完成
         ↓（超时未支付）
       自动取消
```

### 发货与收货
- 供货商发货（PC端操作），商品从供货商直发居民
- 收货：可手动确认，超时**7天**自动确认收货

### 退款
- 居民发起 → 供货商直接处理（平台管理员也可直接处理）
- 支持**部分退款**
- 钱款**原路退回**

### 团长收益
- 平台设置分佣比例
- 根据订单金额自动计算佣金
- 收益到平台账户，团长申请提现，线下打款

## 三、周边商家板块 — 主流程

### 门店管理
- 供货商在PC端编辑门店信息及商品
- 商品库与团购商品**独立**
- 商品设置库存，缺货自动下架

### 用户下单
1. 居民端查看附近门店，**按距离排序**
2. 选择门店 → 选择商品 → 下单支付
3. 支付完成后生成**数字码（手机号后四位）**

### 订单状态
```
待支付 → 备货中 → 待取货 → 已完成
```

### 取货与核销
- **只支持自提**，不支持配送
- 供货商点"备货完成" → 订单进入待取货
- 用户到店取货：出示数字码 → 供货商核对手机号后四位
- 用户取货后手动点"已完成"
- 备货完成后**7天**自动完成

### 退款
- 未取货可退款（自动退款）
- 取货后**不可退款**
- 到店发现商品有问题 → 不做收货动作，点击退货
- 备货超时不做自动退款，居民自行决定是否手动退款

## 四、社区论坛板块

| 功能点 | 规则 |
|--------|------|
| 发帖审核 | **不需要审核**，发帖后立即显示 |
| 内容类型 | 支持文字、图片、视频 |
| 内容检测 | 对接**敏感词检测** |
| 分类 | **平台预设** |
| 互动 | 点赞、评论、收藏、举报 |
| 关注 | 支持关注其他用户，查看对方动态 |
| 置顶/精华 | **不设** |
| 管理 | 平台管理员可删除帖子、封禁用户 |

---

## 五、知识问答板块

| 功能点 | 规则 |
|--------|------|
| 发布 | 直接发布 + 敏感词检测，**无需审核** |
| 分类 | **平台预设** |
| 回答 | 支持多个回答，**不区分最佳答案** |
| 答案可见性 | **答案对其他用户隐藏**（仅提问者可见） |
| 回答互动 | 仅支持**点赞、打赏**（不支持评论、举报） |
| 打赏方式 | 提问者主动给，平台设置金额区间，提问者在区间内选择 |
| 打赏规则 | 可给多个回答者打赏 |
| 打赏资金 | 到平台账户，用户申请提现，**线下打款** |
| 问题有效期 | **无有效期**，提问者手动下架 |
| 下架后 | 已下架问题不再展示 |
| 管理 | 平台管理员可删除问题/回答 |

## 六、异常路径

### 团购订单异常
| 场景 | 处理 |
|------|------|
| 支付超时 | 订单自动取消 |
| 缺货 | 商品设库存，缺货自动下架，根本下不了单 |
| 物流异常 | 居民申请退款，供货商和平台线下处理 |
| 退款被拒 | 不做申诉流程，提示用户可直接联系平台 |

### 周边商家异常
| 场景 | 处理 |
|------|------|
| 备货超时 | 不做自动退款，居民自行决定是否手动退款 |
| 到店发现商品问题 | 不做收货，点击退货退款 |

### 通用异常
| 场景 | 处理 |
|------|------|
| 网络异常 | 操作直接失败，不做本地缓存 |
| 微信登录失败 | 不支持备选登录方式 |
