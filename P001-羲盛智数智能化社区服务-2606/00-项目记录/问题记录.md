## 一、已解决问题

### 问题 1：v1.0 居民端原型 HTML 结构严重错误 🔴致命

**发现时机**: 阶段六第一轮生成后，PM 要求自检  
**问题描述**: 子Agent生成的居民端原型HTML（991行）中：
- body内存在重复的 `<style>` CSS块
- 全部JavaScript代码（约308行）裸露在 `<script>` 标签外部，页面显示源代码文字

**根因**: 派发子Agent生成HTML后，主Agent未做产出物结构完整性校验就直接交付。

**修复**: 删除body内重复CSS块和裸露JS代码（991行→683行）。

**预防措施**: 制定**HTML产出物5项自检清单**，每次生成后强制执行：
1. `<script>` 标签是否正常包裹所有JS代码
2. 是否有重复的 `<style>` / `<script>` 块
3. 关键函数（navTo/goBack/showToast/switchTab）是否仅定义一次
4. 核心DOM元素（navBar/tabBar/toast/modalOverlay）是否存在
5. 浏览器实机预览确认无白屏/乱码/控制台报错

### 问题 2：v2.0 底部导航丢失 🔴严重

**发现时机**: 阶段六 v2.0 生成后，PM 预览发现  
**问题描述**: `phone-frame` 硬编码 `height:812px` + `overflow:hidden`，在屏幕高度不足时底部 Tab-bar 被裁剪隐藏。

**根因**: 未考虑不同显示器分辨率的适配，`overflow:hidden` 导致超出部分直接被裁。

**修复**: `phone-frame` 添加 `max-height:calc(100vh - 40px)`，自适应视口高度。

---

### 问题 3：v2.0 组件重叠 🔴严重

**发现时机**: 与底部导航丢失同时发现  
**问题描述**: flex 容器内子元素（content-area、page-inner）在内容超出时高度计算不准确，组件互相重叠。

**根因**: 
- `.content-area` 未设置 `min-height:0`，flex 子元素默认 `min-height:auto` 导致撑开
- `.page-inner` 同理
- `.tab-bar` z-index 不够高（100），被页面层覆盖

**修复**:
- `.content-area` 添加 `min-height:0`
- `.page-inner` 添加 `min-height:0`  
- `.page` 添加 `overflow:hidden`
- `.tab-bar` z-index 从 100 提升至 1000

---

### 问题 4：v2.0 SVG 图标 CSS 变量写法不兼容 ⚠️中等

**发现时机**: 阶段六 v2.0 生成时，编写规范时预防性发现  
**问题描述**: 团长端v1.0使用 `fill="var(--tab-icon-color, #B2BEC3)"` 写法，部分浏览器不支持CSS变量在SVG属性中。

**根因**: CSS自定义属性在SVG presentation属性中存在兼容性问题。

**修复**: v2.0全部改用 `fill="currentColor"` / `stroke="currentColor"` + CSS类（`.tab-item.active .tab-icon { color: #FF6B35; }`）控制颜色。

### 问题 6：知识问答与论坛不应合并 ⚠️体验

**发现时机**: 阶段六 v1.0 PM预览反馈  
**问题描述**: v1.0将论坛和问答放在同一个TAB下（子Tab切换），PM认为问答应该独立展示。

**根因**: 论坛和问答是两个不同性质的板块（公开交流 vs 隐私问答），合并导致信息层级混乱。

**修复**: v2.0底部导航从4个Tab扩展为5个Tab：首页 / 周边商家 / 论坛 / 问答 / 我的。

## 三、v3.0 待修复问题（新技能自检发现）

### 问题 9：居民端底部导航违反"用户视角"原则 🔴架构

**发现时机**: 阶段六，加载更新后的 `prototype-rules.md` 自检发现  
**问题描述**: 现行v2.0底部导航（首页/周边商家/论坛/问答/我的）直接把系统模块名作为TAB，违反导航设计原则：
- "周边商家""论坛""问答"是后台模块视角，不是用户视角
- 5个Tab中3个是业务模块入口，用户并不需要频繁在"周边商家"和"论坛"之间切换

**新规则要求**：
- 底部导航只能使用用户视角词（首页/好物/社区/我的等）
- 业务模块入口放在首页金刚区
- TAB数量不超过5个

**修正方案（v3.0）**：

| Tab | 定位 | 
|:--:|------|
| 首页 | 聚合展示（Banner+金刚区+推荐） |
| 好物 | 购物（团购团长列表+周边商家门店列表合并） |
| 社区 | 邻里交流（论坛+问答子Tab） |
| 我的 | 个人中心 |

消息通知：从底部Tab移除，改为各页面**顶部导航栏右侧铃铛图标**全局访问。

### 关于团长端导航

**自检结论**：团长端底部导航（首页/订单/收益/我的）**不需要修改**。

团长端的4个Tab均从用户（团长）的工作流视角出发：
- 首页 = 我的主页+商品展示（核心日常）
- 订单 = 管理名下订单（日常任务）
- 收益 = 查看分佣收入（核心利益）
- 我的 = 个人设置+消息

这些Tab不是系统模块名，而是团长的工作场景梳理，符合"用户视角"原则。
