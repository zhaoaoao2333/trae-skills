## 二、项目概述

### 2.1 背景

本项目为学校科研项目，全新建设，最终将部署到真实社区使用。项目目标是为社区提供一站式智能化服务，涵盖团购、到店购物、社区交流、知识问答四大核心场景。

### 2.2 建设目标

构建一个以微信小程序为载体的社区服务平台，连接居民、团长、供货商三方角色，实现团购分销、周边商家到店自提、社区内容互动、知识问答互助四大业务闭环。

### 2.3 目标用户

| 角色 | 端口 | 核心诉求 |
|------|------|---------|
| 居民 | 居民端微信小程序 | 团购下单、到店购物、社区交流、知识问答 |
| 团长 | 团长端微信小程序 | 展示商品、查看订单、分享商品、查看收益 |
| 供货商 | PC管理后台 | 管理商品、设置折扣、管理门店、发货、处理退款 |
| 平台管理员 | PC管理后台 | 管理团长/供货商、设置分佣、内容审核、平台运营 |

### 2.4 项目边界

**包含：**
- 居民端微信小程序（团购、周边商家、社区论坛、知识问答、个人中心）
- 团长端微信小程序（商品展示、订单查看、收益管理、个人中心）
- PC管理后台（供货商端 + 平台管理员端）

**不含：**
- iOS/Android 原生 App
- Web 端（非管理后台）
- 配送物流系统（团购由供货商直发，周边商家仅自提）
- 在线客服即时通讯
- 账号注销功能
- 第三方平台比价
- 论坛置顶/精华功能
- 问答最佳答案评选
- 支付之外的第三方集成（如地图导航、语音输入等）

## 三、核心业务流程

### 3.1 居民端 — 身份认证流程

**正向路径：**
1. 居民打开居民端小程序，进入首页
2. 浏览内容（支持游客模式，不登录可浏览部分内容）
3. 触发需登录操作（下单/发帖/提问）时，弹出微信授权登录
4. 微信授权获取手机号，用户自行设置头像昵称
5. 登录成功，进入对应操作页面

**取消路径：**
- 用户拒绝微信授权 → 停留在当前页面，保持游客模式

**异常路径：**
- 微信登录服务不可用 → 操作直接失败，提示「登录失败，请稍后重试」，不支持备选登录方式

### 3.2 居民端 — 团购流程

**正向路径：**
1. 居民进入首页，浏览团长列表
2. 选择团长，进入团长主页（查看公告、商品分类列表、最近订单脱敏信息、评价数据）
3. 在团长主页按分类/排序（价格/销量/最新）筛选商品，或搜索当前团长名下商品
4. 将商品加入购物车（支持多商品）
5. 进入购物车，确认商品后点击下单
6. 选择收货地址（一笔订单仅一个地址），填写备注
7. 提交订单，系统校验库存并占用库存，生成待支付订单
8. 调用微信支付完成付款
9. 支付成功，订单状态变为「待发货」
10. 供货商PC端发货，订单状态变为「待收货」
11. 居民收到商品后手动确认收货，或超时7天自动确认收货
12. 订单状态变为「已完成」

**取消路径：**
- 提交订单后15分钟内未完成支付 → 订单自动取消，库存释放
- 用户主动取消待支付订单 → 库存释放

**异常路径：**
- 库存不足 → 下单时提示「库存不足」，阻止下单
- 缺货 → 商品设库存，缺货自动下架，用户不可见
- 微信支付失败 → 提示「支付失败，请重试」，订单保持待支付状态
- 支付超时 → 15分钟倒计时结束自动取消订单，库存释放
- 物流异常 → 居民申请退款，供货商和平台线下处理
- 退款被拒 → 提示「退款申请被驳回，如有疑问请联系平台客服」
- 网络异常 → 操作直接失败，不做本地缓存

### 3.3 居民端 — 周边商家流程

**正向路径：**
1. 居民进入「周边商家」TAB
2. 查看附近门店列表，按直线距离排序，支持按商品分类筛选
3. 选择门店，查看门店信息和商品列表
4. 选择商品，填写备注，提交订单
5. 微信支付（超时15分钟自动取消）
6. 支付成功，生成数字码（手机号后四位），订单进入「备货中」
7. 供货商备货完成后标记「备货完成」，订单进入「待取货」
8. 居民到店出示数字码（手机号后四位），供货商核对
9. 居民取货后在订单中点击「确认取货」，订单变为「已完成」
10. 若居民未手动确认，备货完成后7天自动完成

**取消路径：**
- 支付超时15分钟 → 订单自动取消
- 未取货时可手动申请退款

**异常路径：**
- 备货超时 → 不做自动退款，居民自行决定是否手动退款
- 到店发现商品有问题 → 不做取货确认，点击退货退款
- 取货后 → 不可退款
- 网络异常 → 操作直接失败

### 3.4 居民端 — 社区论坛流程

**正向路径：**
1. 居民进入社区论坛，顶部Tab切换：推荐（全部帖子）/ 关注（已关注用户动态）
2. 按分类筛选帖子
3. 点击帖子进入详情页，查看帖子内容和评论区
4. 可进行：点赞、收藏、多层嵌套评论、举报、关注发布者
5. 发帖：填写标题、正文（文字/图片最多9张/视频最大100MB）、选择分类 → 提交后即时显示（无审核，经敏感词检测）
6. 删除自己的帖子或评论

**异常路径：**
- 敏感词检测命中 → 拦截发布，提示「内容包含敏感词，请修改后重试」
- 内容被举报 → 平台管理员审核后处理（删除/忽略）
- 发布者被平台封禁 → 其历史帖子仍可见，但发布者标识为已封禁

### 3.5 居民端 — 知识问答流程

**正向路径：**
1. 居民进入知识问答模块，浏览问题列表（按分类筛选）
2. 点击问题进入详情页，查看问题和回答（仅提问者可见全部回答，其他用户看不到任何回答内容）
3. 提问：填写标题（有字数限制）、正文（无限制）、选择分类（单选）→ 发布（无审核，经敏感词检测）
4. 回答：对任意问题进行回答，正文无限制
5. 回答者之间互动：仅支持点赞和打赏（无评论、无举报）
6. 打赏：提问者在平台预设区间内选择金额，可给多个回答者打赏
7. 被打赏者申请提现，线下打款
8. 提问者可编辑问题、手动下架问题（无有效期限制）

**异常路径：**
- 敏感词检测命中 → 拦截发布
- 问题被平台管理员删除 → 问题不可见，已发生的打赏不退回
- 下架问题 → 问题不再展示，已发生的打赏不退回
- 打赏提现 → 线下打款，平台管理员审核处理

### 3.6 居民端 — 退款流程

**团购退款：**
1. 居民在订单详情页发起退款申请，选择退款原因、退款金额（支持部分退款）
2. 退款金额由系统按商品金额和数量自动计算
3. 供货商PC端收到退款申请，1天内处理（同意/驳回）
4. 1天未处理 → 系统自动同意退款
5. 退款同意后，钱款原路退回
6. 退款被驳回 → 提示用户联系平台

**周边商家退款：**
1. 未取货状态下，居民可发起退款
2. 取货后不可退款
3. 到店发现商品问题 → 不做取货动作，点击退货

### 3.7 团长端 — 核心流程

**商品展示与分享：**
1. 团长打开团长端小程序，首页即团长主页
2. 查看名下全部商品（供货商挂靠的商品），按搜索/分类/排序浏览
3. 团长仅可查看，不可编辑或新增商品
4. 可分享团长主页链接或单个商品链接给居民

**订单查看：**
1. 进入订单TAB，查看名下所有团购订单
2. 按状态筛选：待支付 / 待发货 / 待收货 / 已完成
3. 查看订单详情（含不脱敏的居民信息）

**收益管理：**
1. 进入收益TAB，查看累计收益和可提现余额
2. 查看分佣明细（每笔订单金额、分佣比例、佣金）
3. 申请提现（填写提现金额，需满足最小提现金额）
4. 提现到平台账户，线下打款，团长查看提现状态

### 3.8 身份转换流程（居民→团长）

1. 居民在个人中心点击「申请团长」
2. 填写姓名、手机号、身份证号、申请理由
3. 提交申请，进入待审核状态
4. 平台管理员PC端审核（通过/驳回）
5. 驳回后可重新申请
6. 通过后身份切换为团长，此后只能使用团长端小程序
7. 团长和居民身份互斥，不可同时拥有

### 3.9 PC管理端 — 核心流程概览

**供货商端：**
- 商品管理：新增/编辑/上下架商品、设置库存（团购商品和周边商品两套独立库）
- 团购挂靠：手动将商品挂靠到团长，设置各团长折扣价
- 门店管理：编辑门店信息（店名、地址、定位、商品列表）
- 订单处理：团购发货、周边商家备货、订单状态管理
- 退款处理：审核退款（同意/驳回），支持部分退款

**平台管理员端：**
- 用户管理：管理居民/团长账号，封禁/解封
- 团长审核：审核团长申请
- 分佣设置：设置团长分佣比例
- 内容审核：帖子/评论审核、举报处理、敏感词管理
- 分类管理：预设论坛和问答分类
- 打赏设置：设置问答打赏金额区间
- 提现审核：审核团长收益提现、问答打赏提现

## 四、功能模块详细说明

---

### 4.1 A1 用户体系 | 高优 | 居民端

**目的：** 居民身份认证与基础信息管理，为所有需登录功能提供用户标识。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |
|--------|------|------|---------|
| 用户ID | 系统唯一标识 | 系统自动生成 | 不可变更 |
| 微信手机号 | 加密存储 | 微信授权获取 | 不可变更 |
| 头像 | URL | 用户自行设置 | 用户编辑 |
| 昵称 | 文本 | 用户自行设置 | 用户编辑 |

**内容来源：** 微信授权接口 + 用户手动输入。

**操作：**
- 微信授权登录（触发时机：用户执行下单/发帖/提问等需登录操作时）
- 编辑头像和昵称

**业务规则：**
- 支持游客模式浏览（不登录可浏览部分内容，如团长列表、论坛帖子）
- 必须登录后才能：下单、发帖、提问、评论、点赞、收藏、关注
- 不支持账号注销
- 不支持备选登录方式，微信登录失败则操作直接失败

**关联模块：** 全部模块（登录后可用）。

**待确认项：** 无。

---

### 4.2 A1-2 收货地址 | 高优 | 居民端

**目的：** 管理居民收货地址，用于团购下单时选择。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |
|--------|------|------|---------|
| 联系人 | 文本 | 用户输入 | 用户编辑 |
| 手机号 | 文本 | 用户输入 | 用户编辑 |
| 省市区 | 三级联动选择 | 用户选择 | 用户编辑 |
| 详细地址 | 文本 | 用户输入 | 用户编辑 |
| 是否默认地址 | 布尔值 | 用户标记 | 用户切换 |

**内容来源：** 用户手动输入。

**操作：**
- 新增地址
- 编辑已有地址
- 删除地址
- 设为默认地址

**业务规则：**
- 地址数量不设上限
- 必须至少保留一个默认地址
- 一笔订单只支持一个收货地址

**关联模块：** A2 团购下单。

**待确认项：** 无。

---

### 4.3 A2 团购板块 | 高优 | 居民端

**目的：** 居民通过团长购买商品，团长按分佣比例获得收益。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |
|--------|------|------|---------|
| 团长列表 | 所有团长概要 | 平台管理员审核通过的团长 | 新增团长时刷新 |
| 团长主页 | 头像、昵称、公告栏、商品分类列表、最近订单脱敏信息、评价数据 | 团长编辑+系统生成 | 实时更新 |
| 商品详情 | 商品名、图片、原价、折扣价、库存、销量 | 供货商PC端挂靠 | 供货商更新 |
| 购物车 | 选中的商品列表 | 用户操作 | 用户增删 |

**内容来源：** 商品数据由供货商PC端创建并挂靠到团长；团长主页内容由团长自行编辑；评价数据由居民评价产生。

**操作：**
- 浏览团长列表
- 进入团长主页，按分类筛选商品
- 按价格/销量/最新排序商品
- 搜索商品（仅当前团长名下，不可跨团长搜索）
- 将商品加入购物车
- 编辑购物车（修改数量、删除商品）
- 下单：选择收货地址，填写备注，提交订单
- 微信支付

**业务规则：**
- 必须先选团长，再看商品（不可直接浏览全平台商品进行比价）
- 下单时系统校验库存，提交订单后立即占用库存
- 支付超时15分钟自动取消订单，库存释放
- 团长主页可分享（团长分享主页链接或单个商品链接给居民）
- 同一商品可挂靠多个团长，每个团长可设不同折扣价

**关联模块：** A1 用户体系、A6 订单管理、A7 消息通知、A8 评价体系。

**待确认项：** 无。

---

### 4.4 A3 周边商家 | 高优 | 居民端

**目的：** 居民查看附近门店并线上下单，到店自提取货。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |
|--------|------|------|---------|
| 门店列表 | 店名、距离（直线距离）、地址 | 供货商PC端管理 | 供货商更新 |
| 商品列表 | 商品名、图片、价格、库存 | 供货商PC端管理 | 供货商更新 |
| 数字码 | 手机号后四位 | 支付成功后系统生成 | 固定不变 |

**内容来源：** 门店和商品由供货商在PC管理端创建和维护。

**操作：**
- 查看附近门店列表（按直线距离排序）
- 按商品分类筛选门店
- 选择门店查看商品
- 下单：选择商品、填写备注
- 微信支付（超时15分钟自动取消）
- 支付成功后查看数字码（手机号后四位）
- 到店取货后手动确认完成

**业务规则：**
- 距离为直线距离，非路径距离
- 仅支持自提，不支持配送
- 数字码无有效期限制
- 供货商备货完成后，订单进入待取货状态
- 备货完成后7天自动确认完成
- 取货后不可退款
- 备货超时不做自动退款，居民自行决定是否手动退款
- 到店发现商品问题，不做收货动作，点击退货

**关联模块：** A1 用户体系、A6 订单管理、A7 消息通知。

**待确认项：** 无。

---

### 4.5 A4 社区论坛 | 中优 | 居民端

**目的：** 社区居民交流互动，发布和浏览帖子。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |
|--------|------|------|---------|
| 帖子 | 标题、正文、图片（最多9张）、视频（最大100MB）、发布人、发布时间、分类 | 用户发布 | 用户编辑/删除 |
| 评论 | 正文、评论人、时间、层级关系 | 用户发布 | 用户删除 |
| 点赞 | 点赞人、时间 | 用户操作 | 实时更新 |
| 收藏 | 收藏人、时间 | 用户操作 | 实时更新 |
| 关注 | 关注关系 | 用户操作 | 实时更新 |

**内容来源：** 用户发布，经敏感词检测。

**操作：**
- 发布帖子（文字 + 图片最多9张 + 视频最大100MB）
- 选择帖子分类（平台预设）
- 点赞帖子
- 收藏帖子
- 多层嵌套评论
- 举报帖子或评论
- 删除自己的帖子或评论
- 关注其他用户
- 查看推荐（全部）/ 关注（已关注用户动态）

**业务规则：**
- 发布无需审核，发帖后立即显示
- 必须经过敏感词检测，命中则拦截发布

- 无置顶/精华功能
- 举报由平台管理员审核后处理（删除帖子/评论或忽略）

### 4.6 A5 知识问答 | 中优 | 居民端

**目的：** 居民提问，其他居民回答，提问者可对满意回答进行打赏。

**信息架构：**

| 信息项 | 类型 | 来源 | 更新方式 |

| 回答 | 正文（无限制）、点赞数、打赏数 | 用户发布 | 不可编辑 |

- 平台管理员可删除问题/回答

### 5.6 主要交互流程

**流程三：论坛发布与互动（居民端）**
```
社区TAB → 论坛子Tab → 帖子列表 → 点击帖子 → 帖子详情

社区TAB → 论坛子Tab → 发帖按钮 → 发帖页 → 提交 → 返回帖子列表
```

```
社区TAB → 问答子Tab → 问题列表 → 点击问题 → 问题详情
```

**流程五：订单管理与退款（居民端）**

### 5.8 页面呈现方式

原型以单个HTML文件形式输出，内嵌CSS和JavaScript，浏览器可直接打开预览。

**技术实现要求：**
- 使用内嵌CSS（`<style>` 标签）
- 使用内嵌JavaScript（`<script>` 标签）
- 页面切换通过JavaScript控制显示/隐藏或路由模拟
- 图片资源使用内嵌Base64或CSS绘制
- 文件编码：UTF-8
- 无外部依赖，离线可正常查看

**生成策略（两轮生成）：**
- 第一轮：输出设计框架，P0-P2完整页面 + P3骨架（标题+返回按钮+入站可达）
- 第二轮：PM确认后填充P3完整内容 + 全链路校验 + 各状态覆盖完善

### 5.9 交互规范总则

**导航规范：**
- 底部导航：居民端4个TAB，团长端4个TAB
- 图标：选中态实心，非选中态线框
- 底部导航切换不支持滑动
- 所有非顶层页面必须有返回按钮（左侧箭头）
- 已生成页面：正确跳转
- 未生成页面：Toast提示「页面正在建设中，即将上线」

**交互闭环（每页五问）：**
1. 从哪里来 -- 入站路径清晰
2. 当前是什么 -- 页面标题/定位明确
3. 到哪里去 -- 出站路径完整
4. 操作后发生什么 -- 每项操作有明确反馈
5. 异常怎么处理 -- 网络错误、空数据、权限不足有对应处理

**消息通知：**
- 未读消息以角标数字展示
- 点击消息跳转对应业务页面

**Toast提示：**
- 操作成功类：绿色对勾 + 文字
- 操作失败类：红色叉号 + 错误原因
- 建设中占位：统一文案「页面正在建设中，即将上线」
