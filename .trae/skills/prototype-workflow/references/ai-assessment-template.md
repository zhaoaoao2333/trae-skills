# AI化可能性评估模板

> 本附录仅用于快速评估AI解决方案的可行性与成本，不追求绝对精确。控制在500字以内，一页纸内完成。
> 
> **目的**：培养PM的AI思考意识，在项目初期快速判断业务问题是否适合用AI解决。

---

## 一、问题定义与AI适配性判断

### 1.1 当前要解决的业务问题

（一句话描述，如"将用户反馈自动分派给对应处理部门"）

### 1.2 当前解决方案及痛点

（如：手动分派，每天耗时3小时，且夜间无法处理）

### 1.3 AI适配性判断（勾选）

| 判断项 | 是否满足 | 说明 |
|--------|---------|------|
| 有大量历史数据可学 | [ ] 是 / [ ] 否 | 如：有过去1年、共2万条已分派好的工单记录 |
| 任务定义明确，专家能轻松判断对错 | [ ] 是 / [ ] 否 | 如：普通客服也能分清楚这是"物流投诉"还是"质量问题" |
| 容忍一定程度的错误 | [ ] 是 / [ ] 否 | 如：分错了部门，人工转派一下即可，不会造成资金损失 |
| 需要规模化、7x24小时处理 | [ ] 是 / [ ] 否 | 如：夜间工单也需即时响应 |

**结论**：
- 4项全部满足 → AI适配性**极高**，强烈推荐尝试
- 满足3项 → AI适配性**良好**，可尝试
- 满足2项 → AI适配性**一般**，需谨慎评估
- 满足1项或0项 → AI适配性**低**，建议寻找其他方案

## 使用说明

1. **填写时机**：项目启动阶段（阶段一/二），在明确业务问题后填写
2. **填写人**：PM主导，技术顾问协助
3. **时间控制**：15-30分钟完成，不追求精确
4. **输出用途**：
   - 判断是否需要引入AI解决方案
   - 为后续技术方案选型提供依据
   - 培养PM的AI思考意识
