# 优先级体系

## 页面优先级

| 级别 | 定义 | 生成要求 |
|------|------|---------|
| P0 | 核心页 | 完整生成 |
| P1 | 配套页 | 导航完整 |
| P2 | 参考页 | 占位 |
| P3 | 可延后页 | 首轮出骨架，第二轮填充 |

## 模块优先级

| 级别 | 定义 |
|------|------|
| 高优 | 核心操作，必须实现 |
| 中优 | 辅助信息，提升体验 |
| 低优 | 补充内容，可延后 |

## 路径优先级

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| 主路径 | 核心操作流程 | 画完整闭环 |
| 次要路径 | 辅助操作流程 | 画关键节点 |
| 异常路径 | 错误/边界情况 | 画关键决策点 |

## 生成顺序

严格按 P0 → P1 → P2 → P3 顺序生成，不得跳级。

每批生成后，已生成页面间必须有完整交互链路。
