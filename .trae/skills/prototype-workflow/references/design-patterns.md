# 设计模式库

> 常见设计问题的解决方案，AI遇到类似问题时直接套用。
>
> 每个模式包含：**问题描述 → 解决方案 → 适用场景 → 示例代码 → 注意事项**。

---

## 模式1：分区模式

**问题**：首页信息太多，如何组织？

**解决方案**：按功能分区，从上到下依次排列：Banner→金刚区→横向滚动→纵向列表。

**适用场景**：电商首页、本地生活首页、内容平台首页。

**示例**：
```
首页分区：
├─ 顶部搜索区 [核心操作]
├─ 金刚区 [功能入口]
├─ Banner轮播 [运营位]
├─ 限时秒杀 [横向滚动，促活]
├─ 分类Tab [筛选]
└─ 商品推荐 [纵向列表，核心内容]
```

**注意事项**：
- 每个分区用留白（16-24px）区分
- 视觉重心在上半屏
- 不同分区使用不同布局方式（网格/横滑/纵向）

## 模式2：信息分层模式

**问题**：列表项信息复杂，如何排布？

**解决方案**：按信息优先级分层排列：标题→描述→标签→价格→操作。

**适用场景**：商品列表、门店列表、订单列表、帖子列表。

**示例**：
```
列表项信息层级：
第一层（最重要）：标题 [16px Bold，最多2行]
第二层（次要）：描述/地址/时间 [14px 灰色]
第三层（辅助）：标签 [10px 品牌色背景]
第四层（操作）：价格+按钮 [14px 红色+44px按钮]
```

**注意事项**：
- 每层信息用间距或字号区分
- 操作按钮放在最右侧或底部
- 超过4层信息考虑精简或折叠

## 模式3：主次分离模式

**问题**：操作按钮太多，界面混乱？

**解决方案**：主操作外露，次操作收敛到更多菜单或ActionSheet。

**适用场景**：详情页、列表项、个人中心。

**示例**：
```
商品详情页操作：
主操作（外露）：加入购物车、立即购买 [底部固定栏]
次操作（图标按钮）：收藏、客服、分享 [底部栏左侧]
更多操作（ActionSheet）：举报、投诉、复制链接 [点击更多]
```

**注意事项**：
- 主操作不超过2个
- 次操作3-5个用图标按钮
- 更多操作超过3个用ActionSheet

## 模式4：分步模式

**问题**：表单太长，用户填写压力大？

**解决方案**：将长表单拆分为多步骤，每步聚焦一个主题。

**适用场景**：注册流程、下单流程、发布流程、设置流程。

**示例**：
```
下单流程分步：
步骤1：确认商品 [商品信息+规格确认]
步骤2：填写地址 [收货人+手机号+地址]
步骤3：选择支付 [支付方式]
步骤4：确认订单 [订单汇总+提交]
```

**注意事项**：
- 每步不超过5个输入项
- 显示进度指示（步骤条）
- 允许返回上一步修改
- 最后一步提供完整信息确认

## 模式5：引导模式

**问题**：无数据时，页面空白，用户困惑？

**解决方案**：插图+引导文案+操作按钮，引导用户完成首次操作。

**适用场景**：空状态页面、新用户首次进入、功能未启用。

**示例**：
```
购物车空状态：
┌──────────────────┐
│     [购物车插图]  │
│   购物车还是空的   │
│  去逛逛，发现好物  │
│   [  去逛逛  ]    │
└──────────────────┘
```

**注意事项**：
- 插图风格与产品一致
- 文案不超过两行
- 按钮文案用动词开头（"去添加"而非"添加"）
- 按钮跳转目标明确

## 模式6：筛选抽屉模式

**问题**：列表内容多，用户需要快速筛选？

**解决方案**：顶部筛选栏+底部弹窗，支持多条件组合筛选。

**适用场景**：商品列表、门店列表、订单列表、搜索结果。

**示例**：
```
筛选交互：
1. 用户点击"筛选"按钮
2. 底部弹出筛选抽屉
3. 抽屉内：分类选择+价格区间+排序方式
4. 用户选择后点击"确定"
5. 列表刷新，显示筛选结果
6. 顶部显示已选筛选条件标签（可删除）
```

**注意事项**：
- 常用筛选条件放顶部快捷栏
- 复杂筛选放底部抽屉
- 已选条件可一键清除
- 筛选结果为空时展示引导

## 模式7：规格弹窗模式

**问题**：商品有多规格，用户如何选择？

**解决方案**：底部弹窗展示规格矩阵，选择后实时更新价格和库存。

**适用场景**：电商商品详情、团购套餐选择、服务预约。

**示例**：
```
规格选择弹窗：
┌──────────────────┐
│  [商品缩略图]     │
│  价格：¥99       │
│  已选：红色/L    │
├──────────────────┤
│ 颜色：○红 ●蓝 ○黑│
│ 尺码：○S ●M ○L  │
├──────────────────┤
│ 库存：剩余23件   │
├──────────────────┤
│    [  确定  ]    │
└──────────────────┘
```

**注意事项**：
- 缺货规格置灰不可选
- 选择后实时更新价格
- 未选全规格时确定按钮禁用
- 显示库存提示（紧张时标红）

## 模式8：左滑操作模式

**问题**：列表项需要快捷操作，但空间有限？

**解决方案**：列表项左滑露出操作按钮（删除/收藏/置顶）。

**适用场景**：消息列表、收藏列表、订单列表、文件列表。

**示例**：
```
左滑操作：
正常态：[头像][标题][时间]
左滑后：[头像][标题][时间] [收藏][删除]
```

**注意事项**：
- 左滑距离不超过屏幕宽度的40%
- 操作按钮不超过3个
- 危险操作（删除）放最右侧，红色背景
- 点击其他区域自动收起

---

## 模式9：二次确认模式

**问题**：重要操作（删除/取消/支付）容易误触？

**解决方案**：点击后弹出确认弹窗，用户确认后才执行。

**适用场景**：删除订单、取消预约、退出登录、清空数据。

**示例**：
```
二次确认弹窗：
┌──────────────────┐
│    确认删除？     │
│  删除后不可恢复   │
│ [取消]  [删除]   │
└──────────────────┘
```

**注意事项**：
- 弹窗标题明确操作内容
- 说明操作后果（不可逆操作必须提示）
- 取消按钮在左，确认按钮在右
- 危险操作按钮用红色

---

## 模式10：骨架屏模式

**问题**：数据加载时白屏，用户以为卡死？

**解决方案**：用灰色占位块模拟内容形状，加载完成后渐显真实内容。

**适用场景**：列表页、详情页、首页、任何有数据加载的页面。

**示例**：
```
骨架屏：
加载前：[灰色块][灰色条][灰色条]
加载后：[真实图片][真实标题][真实价格]
```

**注意事项**：
- 骨架屏形状与真实内容一致
- 使用动画（ shimmer 效果）提示加载中
- 加载超时（10s）显示重试入口
- 优先用于首屏内容

## 模式使用说明

### 选择模式的方法

1. **识别设计问题**（信息太多/操作太多/表单太长/无数据...）
2. **查阅模式库**，找到匹配的模式
3. **套用模式结构**，替换为业务内容
4. **根据场景调整**（增删步骤、调整优先级）

### 模式组合使用

多个模式可以组合：
- 首页 = 分区模式 + 信息分层模式
- 商品详情 = 主次分离模式 + 规格弹窗模式 + 二次确认模式
- 列表页 = 信息分层模式 + 筛选抽屉模式 + 左滑操作模式 + 骨架屏模式
