# 项目管理规则

## 项目资产

### 项目ID
- 格式：P + 三位数字（如 P001、P002）
- 由注册表分配，不重复不回收

### 文件夹命名
- 格式：P编号-项目简称-年月（如 P001-电商APP-2606）

### 标准子目录
```
P编号-项目简称-年月/
├── 00-项目记录/     ← 确认记录、断点续传
├── 01-需求文档/     ← PRD 文档
├── 04-原型/         ← 原型文件
└── 05-交付物/       ← 最终交付
```

### 项目注册表
- 位置：团队共享根目录
- 按状态分表管理

## 项目初始化

新项目必须先创建文件夹和标准子目录，按规范命名。

## 注册表管理

注册表为唯一真实来源，每次里程碑自动更新状态。

## 上下文管理

- 切换项目必须重置上下文
- 检测到异议主动提醒
- 每次确认写记录到 `00-项目记录/`，上下文断了可无缝恢复

## 防幻觉规则

| 置信度 | 处理方式 |
|--------|---------|
| 确定 | 直接陈述 |
| 推测 | 标注「待验证」 |
| 未知 | 直接说不知道 |

禁止：
- 编造竞品功能
- 技术断言
- 行业数据
- 不存在的案例
