# 行业模板库

> 行业模板定义各行业的标准页面结构、组件组合和信息层级。
>
> **模板中不包含具体色值**，颜色、字体、间距从 `prototype-rules.md` 的 Design Token 体系获取。
>
> 模板中使用 CSS 变量引用 Token，如 `var(--color-primary)`、`var(--font-title)`。

---

## 电商行业模板

### 模板：首页

```
布局结构（从上到下）：
├─ 顶部搜索区 [固定，高度56px]
│   ├─ 搜索框 [胶囊型，圆角20px，背景var(--color-bg-tertiary)]
│   └─ 消息铃铛 [右侧，24px图标，红点角标]
│
├─ 金刚区 [2行×4列，8个入口]
│   └─ 每个入口：64px图标 + 12px文字 [var(--font-caption)]
│
├─ Banner轮播 [高度160px，圆角12px]
│   └─ 3-5张，自动轮播5s，底部指示点
│
├─ 限时秒杀 [横向滚动]
│   └─ 卡片：倒计时[红色] + 商品图[1:1] + 现价[加粗红色] + 原价[删除线]
│
├─ 分类Tab [横向滚动，6-8个分类]
│   └─ 选中态：品牌色下划线 + 加粗
│
├─ 商品推荐 [双列网格，瀑布流]
│   └─ 商品卡片模板（见下方）
│
└─ 底部导航栏 [4个Tab，固定底部]
```

**商品卡片模板：**
```html
<div class="product-card">
  <img class="card-img" src="[1:1商品图]">
  <div class="card-info">
    <div class="card-title">[标题，2行截断，var(--font-body)]</div>
    <div class="card-price">
      <span class="price-current">[现价，var(--font-title) 加粗 var(--color-primary)]</span>
      <span class="price-original">[原价，var(--font-caption) 删除线 var(--color-text-tertiary)]</span>
    </div>
    <div class="card-tags">
      <span class="tag-primary">[促销标签，品牌色背景白字]</span>
    </div>
    <div class="card-meta">
      <span>[销量，var(--font-caption) var(--color-text-tertiary)]</span>
      <span>[店铺名，var(--font-caption)]</span>
    </div>
  </div>
</div>
```

**隐含功能：**
- 搜索历史、热词推荐
- 秒杀提醒（设置提醒）
- 商品筛选（价格/销量/综合）
- 下拉刷新、上拉加载

### 模板：商品详情

```
布局结构：
├─ 顶部导航 [返回 + 分享 + 更多]
│   └─ Web/App：右侧有按钮 / 小程序：右侧无按钮（胶囊区）
├─ 商品主图轮播 [1:1，可放大，圆角0]
├─ 价格区
│   ├─ 现价 [var(--font-h1) 加粗 var(--color-primary)]
│   ├─ 原价 [删除线 var(--color-text-tertiary)]
│   └─ 促销标签 [品牌色背景]
├─ 标题区
│   ├─ 商品名称 [var(--font-title)]
│   ├─ 销量 + 评价数 [var(--font-caption)]
│   └─ 分享赚 [按钮]
├─ 规格选择 [点击 → 底部弹窗]
│   └─ 已选：规格名称 [箭头]
├─ 评价区
│   ├─ 评分 [星星 + 分数]
│   ├─ 标签筛选 [好评/有图/追评]
│   └─ 3条评价 [头像+昵称+内容]
├─ 店铺区
│   ├─ 店铺头像 [40px圆形]
│   ├─ 店铺名称 + 评分
│   └─ 进店按钮 [描边按钮]
├─ 详情区 [图文详情，富文本/图片]
└─ 底部固定栏 [固定底部，高度48px]
    ├─ 收藏 [图标按钮]
    ├─ 客服 [图标按钮]
    ├─ 购物车 [图标按钮 + 角标]
    ├─ 加入购物车 [黄色填充按钮]
    └─ 立即购买 [红色填充按钮]
```

**交互：**
- 规格选择 → 底部弹窗 → 选择后更新价格
- 加入购物车 → Toast"已加入购物车" + 购物车角标+1
- 立即购买 → 确认订单页
- 收藏 → 心形图标变色 + Toast

### 模板：发布页

```
布局结构：
├─ 顶部导航 [取消 + "发布" + 发布按钮]
│   └─ 发布按钮：品牌色，禁用态灰色

│   ├─ placeholder："分享你的想法..."

│   ├─ 每张80-100px，1:1，圆角8px
```

## 模板使用说明

### 生成时引用方式

1. **确定行业类型**（电商/社区/本地生活/工具）
2. **选择对应模板**（首页/列表/详情/发布等）
3. **填充业务内容**（替换占位符为具体业务信息）
4. **从Token取样式**（颜色/字体/间距使用CSS变量）
5. **根据PRD调整**（增删模块，调整优先级）

### 模板与Token的关系

```css
/* 模板中使用CSS变量引用Token */
.product-card {
  padding: var(--spacing-card);
  border-radius: var(--radius-card);
  background: var(--color-bg-primary);
}

.card-title {
  font-size: var(--font-body);
  color: var(--color-text-primary);
}

.price-current {
  font-size: var(--font-title);
  font-weight: bold;
  color: var(--color-primary);
}
```
