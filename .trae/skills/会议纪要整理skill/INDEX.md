## 二、子Agent职能一览

| Agent | 角色定位 | 核心职能 | 触发时机 | 文件路径 |
|-------|---------|---------|---------|---------|
| 会议纪要整理Agent | 纪要整理执行体 | 将会议原始记录整理成结构清晰、重点突出、结论明确的标准化会议纪要 | 阶段三步骤3.4 | `01-Agent定义/会议纪要整理Agent.md` |

### Agent核心能力

| 能力模块 | 说明 |
|---------|------|
| 上下文学习 | 自动读取项目已有上下文（PRD/功能清单/历史会议纪要），识别项目术语/人名/功能模块 |
| 核心提炼 | 从冗长录音转写中提取核心结论和决策，区分不同发言人观点 |
| 待办提取 | 识别待办事项、责任人和截止时间，信息不完整标注`[待确认责任人]`等 |
| 主动追问 | 6类必须追问：时间不明确/人员不清楚/目的无法推断/议题边界模糊/责任人不明确/截止时间未提及 |
| 分歧保留 | 保留关键分歧点，不强行统一为"一致通过" |

### 硬约束（6条）

1. 结论必须明确不出现"可能""大概" 2. 每个待办必须有责任人（无明确标注`[待确认责任人]`） 3. 基本信息（时间/地点/参会人/记录人）必须完整 4. 议题逻辑清晰不分散 5. 不确定信息标注`[待确认]`不编造 6. 敏感内容标注`[内部讨论，不外传]`

## 六、快速决策树

> 主Agent根据PM需求，按此树快速路由。

```
PM需求
├─ "整理会议纪要""/meeting" → 启动技能
│   ├─ 阶段一：输入接收与评估
│   │   ├─ 步骤1.1：接收输入（转写/手写/零散要点）
│   │   ├─ 步骤1.2：录音转写预处理（噪音过滤/转写错误/发言分段）
│   │   ├─ 步骤1.3：评估输入完整度
│   │   ├─ 步骤1.4：逻辑自洽检查（6类问题）
│   │   └─ 步骤1.5：评估内容复杂度
│   ├─ 阶段二：基本信息提取与结构确认
│   │   ├─ 步骤2.1：提取基本信息（时间/地点/参会人/记录人）
│   │   ├─ 步骤2.2：议题识别与归类
│   │   └─ 步骤2.3：结构确认（复杂会议强制，简单会议跳过）
│   │       └─ 加载：会议纪要模板.md（结构确认模板）
│   ├─ 阶段三：内容整理与纪要生成
│   │   ├─ 步骤3.1：核心结论提炼（3-5条，每条30字内）
│   │   ├─ 步骤3.2：议题讨论整理（口语转书面，保留分歧）
│   │   ├─ 步骤3.3：待办事项提取（内容/责任人/截止时间/状态）
│   │   ├─ 步骤3.4：调用会议纪要整理Agent结构化输出
│   │   │   └─ 加载：会议纪要整理Agent.md、会议纪要整理规范.md、会议纪要模板.md
│   │   └─ 步骤3.5：质量自检（11项）
│   └─ 阶段四：交付与经验沉淀
│       ├─ 步骤4.1：交付纪要（Markdown格式）
│       └─ 步骤4.2：整理归纳问题与经验
│
└─ 会议类型判断 → 选择场景模板
    ├─ PM提到"需求评审" → 需求评审会模板
    ├─ PM提到"复盘""总结" → 项目复盘会模板
    ├─ PM提到"方案讨论""选型" → 方案讨论会模板
    ├─ PM提到"站会""daily" → 日常站会模板
    ├─ PM提到"客户沟通""客户会议" → 客户沟通会模板
    └─ 其他 → 通用输出格式
```

## 七、四阶段工作流速览

| 阶段 | 名称 | 核心目标 | 关键输出 | PM确认点 |
|------|------|---------|---------|---------|
| 一 | 输入接收与评估 | 接收原始记录，预处理转写，评估完整度 | 输入评估结论 | 确认输入可用 |
| 二 | 基本信息提取与结构确认 | 提取基本信息，识别议题，确认结构 | 基本信息+议题结构 | 确认结构（复杂会议） |
| 三 | 内容整理与纪要生成 | 提炼结论，整理讨论，提取待办，自检 | 标准化会议纪要 | 确认纪要内容 |
| 四 | 交付与经验沉淀 | 交付纪要，整理经验 | 最终纪要+经验归纳 | 确认交付 |

## 维护规则

1. **每次补丁更新时同步更新本文件**：新增/修改规则、模板后，同步更新对应索引章节和版本记录
2. **索引不展开细节**：本文件是索引不是文档，每项只写一句话摘要
3. **快速决策树保持最新**：新增会议类型或步骤时，同步更新决策树
4. **版本记录连续**：每次更新追加一行，不删除历史记录
