## 二、子Agent职能一览

| Agent | 角色定位 | 核心职能 | 触发时机 | 文件路径 |
|-------|---------|---------|---------|---------|
| 思维导图Agent | 结构化梳理工具 | 将需求/功能清单/PRD/会议纪要输出为逻辑清晰的思维导图，支持上下文学习、主动反问、行业结构自动补充 | 阶段四步骤4.2 | `01-Agent定义/思维导图Agent.md` |

### Agent核心能力

| 能力模块 | 说明 |
|---------|------|
| 上下文学习 | 自动读取项目已有上下文（PRD/功能清单/业务流程），识别项目类型应用对应行业结构 |
| 需求整理 | 将模糊零散输入整理成结构清晰框架，自动补全隐含模块（标注`[AI补充]`），识别矛盾点 |
| 主动反问 | 5种必须反问情况：输入模糊/多种结构方式/关键模块缺失/行业不确定/优先级不足。每次不超过3个问题 |

### 硬约束（12条）

1. 必须先确认框架再展开 2. 详略有区分 3. 不设层级上限 4. 节点文字功能导向15字/页面结构导向25字 5. AI补充标注`[AI补充]` 6. 字段类节点合并 7. 默认.mm+.md双格式 8. 页面结构导向遵循唯一入口规则 9. 核心页面需交互效果描述 10. 核心页面需4种状态覆盖 11. mm文件UTF-8编码 12. AI补充不超过总节点20%

## 六、快速决策树

> 主Agent根据PM需求，按此树快速路由。

```
PM需求
├─ "生成思维导图""梳理结构" → 启动技能
│   ├─ 阶段一：确认保存位置（项目目录/03-思维导图/）
│   ├─ 阶段二：背景了解 + 行业规范检查
│   ├─ 阶段三：需求梳理
│   │   ├─ 步骤3.2：确定导向模式
│   │   │   ├─ 功能导向（默认）→ 加载：思维导图生成规范.md
│   │   │   └─ 页面结构导向 → 加载：页面结构导向思维导图规范.md
│   │   └─ 步骤3.3：输出待确认问题清单
│   ├─ 阶段四：思维导图生成
│   │   ├─ 步骤4.1：结构确认（强制）
│   │   ├─ 步骤4.2：调用思维导图Agent展开内容
│   │   │   └─ 加载：思维导图Agent.md、思维导图模板.md
│   │   │   └─ 生成模式判断：
│   │   │       ├─ 逐层生成（默认）→ 先输出一级框架，PM确认后逐层展开
│   │   │       └─ 一次性完整版 → PM要求时，忽略层级限制直接输出完整导图
│   │   └─ 步骤4.3：质量检查（功能导向12项/页面结构导向10项）
│   └─ 阶段五：交付.mm+.md + 经验沉淀
│
├─ 导向模式判断
│   ├─ PM要求"页面结构""原型输入源""页面跳转" → 页面结构导向
│   └─ 其他情况 → 功能导向（默认）
│
└─ 生成模式判断
    ├─ PM说"先看框架""逐步展开"/未明确 → 逐层生成
    └─ PM说"一次性生成""完整版""直接输出" → 一次性完整版
```

## 七、五阶段工作流速览

| 阶段 | 名称 | 核心目标 | 关键输出 | PM确认点 |
|------|------|---------|---------|---------|
| 一 | 项目初始化 | 确认保存位置，初始化上下文 | 输出目录+上下文记忆文件 | 确认启动 |
| 二 | 背景了解 | PM简述背景，行业规范检查 | 背景记录 | 确认进入梳理 |
| 三 | 需求梳理 | 整理框架，确定导向模式，输出待确认清单 | 待确认问题清单+导向模式确认 | 确认问题清单 |
| 四 | 思维导图生成 | 结构确认→展开内容→质量检查 | .mm+.md双格式文件 | 结构确认/最终产物 |
| 五 | 交付与经验沉淀 | 交付产物，整理经验 | 产物+经验归纳 | 确认交付 |
