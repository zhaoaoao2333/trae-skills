# 思维导图模板

> 本文件提供思维导图输出的标准格式和各场景模板骨架。
> 遵循 `references/思维导图生成规范.md` 中的规则。

---

## 一、结构确认模板

输出完整导图前，必须先输出以下结构确认内容：

```
【核心主题】：XXX

【一级分支预览】：
- 分支1：XXX — 【详细展开】核心业务流程
- 分支2：XXX — 【简要处理】辅助功能模块
- 分支3：XXX — 【简要处理】字段清单类

以上结构中，标注"详细展开"的部分会展开到3-4级，标注"简要处理"的部分会控制在1-2级或合并概括。确认后我将展开完整导图。需要调整详略策略请告诉我。
```

## 二、Markdown 输出格式

### 格式规则

- 核心主题使用一级标题：`# 核心主题`
- 一级分支：`- ` 开头，顶格
- 二级分支：缩进 2 个空格后 `- ` 开头
- 三级分支：缩进 4 个空格后 `- ` 开头
- 四级分支：缩进 6 个空格后 `- ` 开头
- 统一使用 `- ` 作为列表标记，不使用数字序号
- 节点文字后不加空行，父节点与第一个子节点之间不加空行
- 不同一级分支之间加一个空行分隔

### 完整格式示例

```
# 电商平台产品功能清单

- 用户端
  - 首页
    - 搜索栏
    - 轮播图
    - 金刚区（8个入口）
    - 商品推荐流
  - 商品浏览
    - 分类浏览
      - 左侧类目导航
      - 右侧商品列表
      - 筛选与排序
    - 商品搜索
      - 关键词搜索
      - 搜索历史
      - 搜索结果筛选
    - 商品详情
      - 主图轮播
      - 价格与优惠信息
      - 规格选择（弹窗）
      - 商品参数 [待确认]
      - 用户评价入口
  - 购买流程
    - 加入购物车
      - 点击反馈动效
      - 购物车角标更新
      - 已售罄时按钮置灰
    - 购物车管理
      - 商品列表（勾选/数量修改/删除）
      - 价格汇总
      - 优惠券选择
      - 空状态引导"去逛逛"
    - 下单结算
      - 确认收货地址
      - 选择支付方式
      - 确认订单金额
      - 提交订单
    - 支付
      - 支付成功→跳转结果页
      - 支付失败→提示原因+重试
      - 支付超时→自动取消+释放库存
  - 订单管理
    - 订单列表（按状态筛选）
    - 订单详情
    - 物流追踪
    - 确认收货
    - 申请售后
  - 个人中心（略）
    - 账号信息管理
    - 收货地址管理
    - 优惠券卡包
    - 收藏与足迹
    - 系统设置（通知、隐私、关于等）

- 商家端
  - 商品管理
    - 商品发布（基本信息字段+规格库存字段，约10项）
    - 商品上下架
    - 库存管理 [待确认]
  - 订单处理
    - 订单列表（待发货/已发货/退款中）
    - 发货操作
    - 退款处理
  - 店铺管理（略）
    - 店铺信息设置
    - 经营数据概览 [待确认]

- 平台运营端
  - 审核管理
    - 商家入驻审核
    - 商品上架审核
  - 活动配置
    - 秒杀场次管理
    - 满减/满折活动配置 [AI补充]
  - 数据统计（略）
    - 经营报表
    - 用户分析 [待确认]
  - 系统设置（略）
    - 权限管理
    - 规则配置

AI补充节点1个，待确认节点3个。
```

## 三、场景模板骨架

### 3.1 产品功能清单

```
# 【产品名】【端类型】产品功能清单

- 【角色/端口1】
  - 【页面1】
    - 【功能点1】
    - 【功能点2】
  - 【页面2】
  - 公共能力
    - 登录/注册
    - 消息通知
    - ...

- 【角色/端口2】（略）
  - 【模块1】
  - 【模块2】
```

### 3.2 业务流程图

```
# 【产品名】【流程名称】主流程

- 【角色1】
  - 【阶段1】
    - 【步骤1】
    - 【步骤2】
    - 步骤2→异常处理（超时/失败/权限不足）
  - 【阶段2】
    - 【步骤1】
    - 【步骤2】

- 【角色2】
  - 【阶段1】
    - 【步骤1】
    - 【步骤2】

- 【系统】
  - 【系统自动处理1】
  - 【系统自动处理2】
```

## 四、页面结构导向模板

> 当PM要求"以页面结构为导向"生成思维导图时，使用以下模板。
> 遵循 `references/03-规则规范/页面结构导向思维导图规范.md` 中的规则。

### 4.1 结构确认模板（页面结构导向）

```
【核心主题】：XXX — 页面架构思维导图

【导向模式】：页面结构导向

【一级分支预览】：
- App端 — 【详细展开】完整页面架构
  - 前置流程：注册登录（X个页面）
  - Tab1首页（一级页面）— 【详细展开】
  - Tab2首页（一级页面）— 【简要处理】
  - ...
- 管理端 — 【详细展开】功能模块架构

【端类型】：App端 + 管理端 / 仅App端 / 仅管理端

以上结构中，标注"详细展开"的页面会展开到板块级（含内容/交互/跳转），标注"简要处理"的页面只列页面名称和核心板块。确认后我将展开完整导图。
```

### 4.2 页面结构导向输出格式（Markdown）

```
# 【项目名】页面架构思维导图

- App端
  - 注册登录流程（前置页面）
    - 引导页
      - 品牌展示区
        - 品牌Logo（居中展示，淡入动画）
        - 品牌标语（多语言文案）
      - 引导内容区
        - 3页滑动引导（核心玩法/社交竞技/锦标赛奖励）
        - 滑动指示器（圆点，当前页高亮）
      - 底部操作区
        - 跳过按钮 → 跳转至：游戏Tab首页（游客模式）
        - 注册按钮 → 跳转至：注册页
    - 注册页
      - ...
  - Tab1首页（一级页面）
    - 顶部资产栏
      - Gold余额显示（点击 → 跳转至：充值中心）
      - Diamond余额显示（点击 → 跳转至：商城）
      - 头像（点击 → 跳转至：个人主页）
    - 游戏列表（金刚区，4列网格）
      - Ludo卡片
        - 封面 + 在线人数 + 快速开始按钮
        - 操作：点击卡片 → 跳转至：匹配等待页
      - Jackaroo卡片（结构同Ludo）
      - 分类Tag筛选
      - 搜索框
    - 底部TabBar
  - Tab2首页
    - → 跳转至：详见Tab2首页展开（如有唯一入口）

- 管理端
  - 赛事管理
    - 锦标赛创建/编辑/删除
      - 创建表单：名称/时间/类型/赛制/奖励/报名条件
      - 名称唯一性校验
      - 时间冲突检测
    - 状态管理
      - 状态流转：草稿 → 报名中 → 进行中 → 已结束
    - 参与者管理
      - 参与者列表：用户信息/报名时间/状态/排名
    - 结果管理
      - 结果录入/修改/确认
      - 奖励发放

AI补充节点X个，待确认节点X个。
```
