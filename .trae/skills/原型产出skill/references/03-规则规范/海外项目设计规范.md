# 海外项目设计规范

> 本文件包含海外项目的设计规范，仅在对应市场项目中加载。
> 当前覆盖：中东海湾地区（沙特、阿联酋、科威特、卡塔尔、巴林、阿曼）
>
> **加载条件**：项目目标市场为海外（特别是阿拉伯语区）时加载。

---

## 一、区域定位

- **核心市场**：中东海湾地区（沙特、阿联酋、科威特、卡塔尔、巴林、阿曼）
- **辅助市场**：北非阿拉伯语区（埃及、摩洛哥等）
- **语言支持**：阿拉伯语（主）、英语（辅）、中文（开发用）

---

## 二、RTL（从右至左）适配规则

- 所有页面布局必须支持镜像翻转（RTL模式）
- 文本对齐：阿拉伯语环境下所有文本默认右对齐
- 图标方向：返回箭头、进度指示器、滑块在RTL下水平翻转
- 列表项：左侧操作按钮移至右侧
- 时间线/步骤条：流向从右向左

### RTL CSS实现
```css
/* RTL模式 */
[dir="rtl"] {
  text-align: right;
}
[dir="rtl"] .nav-back {
  transform: scaleX(-1); /* 返回箭头翻转 */
}
[dir="rtl"] .list-item .li-arrow {
  transform: scaleX(-1);
}
```

## 三、文化禁忌与合规

### 3.1 视觉元素禁忌
- 禁止出现猪、狗等动物形象（除非抽象化处理）
- 女性角色着装需符合伊斯兰规范（长袖、长裤/长裙）
- 避免使用十字架、六角星等宗教符号
- 禁止使用酒精、赌博（真实货币）相关暗示

### 3.2 色彩敏感度
- 绿色：在伊斯兰文化中有积极含义，可用于主品牌色
- 金色/紫色：代表尊贵，适合VIP、高级会员体系
- 避免纯黑色大面积使用（与哀悼关联）

### 3.3 内容合规
- 所有UGC内容需经过阿拉伯语关键词过滤
- 聊天系统内置敏感词库（宗教、政治、性相关）
- 用户头像审核机制（AI+人工）

---

## 四、阿拉伯语本地化

### 4.1 翻译原则
- 非直译，使用当地惯用表达（如沙特方言vs埃及方言选择）
- 文本扩展：阿拉伯语翻译通常比英语长20-30%，UI需预留空间
- 数字与文本混排：数字保持从左到右，文本从右到左（BiDi处理）
- 日期：伊斯兰历（可选显示）+ 公历双历显示

### 4.2 字体规范
- **阿拉伯语**：Noto Sans Arabic、Droid Arabic Kufi
- **英语/数字**：SF Pro Display（iOS）、Roboto（Android）
- **中文（开发用）**：PingFang SC、Noto Sans SC

### 4.3 多语言切换
- **切换入口**：设置 > 通用 > 语言设置
- **生效方式**：切换后立即生效，无需重启App
- **语言列表**：阿拉伯语、英语、法语（北非）、乌尔都语（南亚劳工）
- **默认语言**：根据系统语言自动匹配，首次启动可手动选择

## 五、未成年人保护（区域法规）

- **年龄验证**：注册时选择年龄，<18岁进入青少年模式
- **青少年模式限制**：
  - 每日游戏时长：2小时（周五/六/日3小时）
  - 消费限制：禁止充值
  - 社交限制：无法添加陌生好友、无法世界频道发言
  - 内容过滤：过滤不当UGC内容

---

## 六、数据隐私合规

- **合规遵循**：GDPR（欧盟用户）、沙特PDPL、阿联酋数据保护法
- **隐私政策**：注册时必须同意，独立页面可查阅
- **数据导出**：用户可申请导出个人数据（7天内提供）
- **账号注销**：支持彻底注销，15天冷静期后可恢复

---

## 七、内容呈现规范

### 7.1 数字与货币
- **数字格式**：阿拉伯数字统一使用西方阿拉伯数字（0-9），非东阿拉伯数字
- **货币显示**：虚拟货币使用图标+数字格式，如"💰 12,500"
- **价格显示**：真实货币价格需标注币种（USD/SAR/AED等）
- **大数字缩写**：K（千）、M（百万）、B（十亿）

### 7.2 时间格式
- **相对时间**："刚刚"、"5分钟前"、"2小时前"、"昨天"、"3天前"
- **绝对时间**：根据地区显示格式（沙特用DD/MM/YYYY）
- **倒计时**：MM:SS格式，最后10秒变红色+闪烁提示

### 7.3 文本截断
- **单行**：末尾省略号，max-width 100%
- **多行**：最多3行，超出省略号+展开按钮
- **用户名**：最长12个字符，超出中间省略
