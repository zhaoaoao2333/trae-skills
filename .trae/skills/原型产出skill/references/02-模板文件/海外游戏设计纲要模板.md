# 海外游戏项目设计纲要模板

> 本模板用于海外游戏项目的原型设计纲要编写。
> 基于Jam3a项目（P008）V3版本提炼，适用于中东海湾地区游戏类App。
> 使用时根据具体项目调整色彩、字体、组件等参数。

---

## 一、设计理念

### 核心关键词
**竞技荣耀 · 深空神秘 · 奢华克制**

### 设计哲学（游戏项目通用）
- **暗色为底，品牌色为魂**：深色背景 + 品牌识别色
- **辅助色点缀**：用于区分层级、增加氛围
- **光效克制**：发光效果仅用于关键交互（选中态、CTA按钮、稀有奖励）
- **科技感字体定调**：标题用科技感字体，强化"竞技平台"属性
- **Emoji图标体系**：原型阶段使用Emoji作为功能图标，降低设计资源依赖

## 二、色彩体系

### 2.1 CSS变量模板（游戏项目参考）

```css
:root {
  /* 背景色 - 游戏项目推荐暗色系 */
  --bg-black: #0a0a0f;       /* 最深背景，页面底色 */
  --bg-dark: #12121a;         /* 次级背景，输入框、资产栏 */
  --bg-card: #1a1a24;         /* 卡片背景 */
  --bg-card-2: #20202c;       /* 卡片Hover背景 */
  --bg-elevated: #252533;     /* 更高层级背景 */

  /* 品牌色 - 根据项目定位调整 */
  --gold: #FFD700;            /* 金色主色 */
  --gold-dim: #c9a700;
  --gold-glow: rgba(255, 215, 0, 0.35);
  --purple: #9D4EDD;          /* 紫色辅助色 */
  --purple-glow: rgba(157, 78, 221, 0.35);

  /* 文字色 */
  --text-primary: #ffffff;
  --text-secondary: #a0a0b0;
  --text-muted: #6b6b80;

  /* 功能色（全行业通用） */
  --green: #2ecc71;  /* 成功/在线 */
  --red: #e74c3c;    /* 错误/危险 */
  --orange: #e67e22; /* 警告/限时 */
  --blue: #3498db;   /* 信息/链接 */

  /* 边框色 */
  --border-subtle: rgba(255, 255, 255, 0.08);
  --border-gold: rgba(255, 215, 0, 0.25);
  --border-purple: rgba(157, 78, 221, 0.25);

  /* 阴影 */
  --shadow-card: 0 2px 12px rgba(0, 0, 0, 0.5);
  --shadow-gold: 0 0 20px rgba(255, 215, 0, 0.3);

  /* 圆角 */
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --radius-xl: 20px;

  /* 尺寸常量 */
  --navbar-h: 52px;
  --tabbar-h: 62px;
  --statusbar-h: 28px;
}
```

### 2.2 色彩使用规则

| 用途 | 颜色 | 说明 |
|------|------|------|
| 页面背景 | `--bg-black` | 永远是最底层 |
| 卡片/容器 | `--bg-card` | 比背景亮一级 |
| 输入框 | `--bg-dark` | 输入区域用暗色 |
| 主CTA按钮 | 品牌色渐变 | 最重要的操作 |
| 次要CTA按钮 | 辅助色渐变 | 辅助重要操作 |
| 选中态 | 品牌色 | 当前激活项 |
| 禁用态 | `--bg-elevated` + `--text-muted` | 灰色不可操作 |

### 2.3 渐变使用规范
```css
/* 品牌色渐变 - 主按钮 */
background: linear-gradient(135deg, var(--gold) 0%, #ffaa00 100%);

/* 辅助色渐变 - 次要按钮 */
background: linear-gradient(135deg, var(--purple) 0%, var(--purple-dim) 100%);

/* 页面底色 */
background: linear-gradient(135deg, #0a0a12, #12121f);

/* 引导页底色 */
background: radial-gradient(circle at 50% 40%, #1a0a2e 0%, #0a0a0f 70%);
```

### 2.4 段位徽章渐变（竞技游戏专用）

## 五、布局模式

### 5.1 页面容器结构
```
page（100%容器）
├── status-bar（28px，可选）
├── navbar（52px，可选）
│   ├── nav-back（返回按钮，左）
│   ├── nav-title（居中标题，品牌字体）
│   └── nav-right（操作按钮，右）
├── asset-bar（资产栏，可选，游戏相关页面）
├── page-scroll（滚动区域）
│   ├── section（标准模块）
│   │   ├── section-header（标题+更多）
│   │   └── 内容区域
│   └── ...
└── tabbar（62px，仅一级页面）
```

### 5.2 标准模块（Section）
```css
.section { padding: 14px; }
.section-header { display: flex; align-items: center; justify-content: space-between; margin-bottom: 10px; }
.section-title { font-family: 'Orbitron', sans-serif; font-size: 14px; font-weight: 700; color: var(--gold); }
```

### 5.3 网格系统
```css
.grid-2 { display: grid; grid-template-columns: repeat(2, 1fr); gap: 10px; }
.grid-3 { display: grid; grid-template-columns: repeat(3, 1fr); gap: 10px; }
```

### 5.4 特殊布局（游戏专用）
- **引导页**：`radial-gradient`背景，居中内容，跳过按钮右上角
- **语聊房**：3列网格，圆形mic-slot

## 七、交互模式

### 7.1 交互反馈规则

| 操作 | 反馈 |
|------|------|
| 按钮点击 | 0.2s transition，hover时上移1px+发光增强 |
| 页面跳转 | 瞬间切换（无过渡动画） |
| 操作成功 | Toast提示 |
| 操作失败 | Toast提示错误信息 |
| 加载中 | Spinner旋转动画 |
| 空数据 | Empty State组件 |
| 危险操作 | Modal二次确认 |
| 游戏卡片Hover | 边框变品牌色+上移2px+发光 |

### 7.2 游戏特定交互
- **匹配等待**：实时显示匹配进度、预计等待时间、取消按钮
- **对局中**：禁止系统返回手势（防误触），提供"确认退出"二次确认
- **结算动画**：连胜特效、段位变化动画、奖励飞入效果

## 八、动画系统

### 8.1 关键帧定义
```css
@keyframes pulse-ring  { 0%{scale(0.8);opacity:0.8} 100%{scale(2.2);opacity:0} }
@keyframes pulse-glow  { 0%,100%{box-shadow:0 0 10px var(--gold-glow)} 50%{box-shadow:0 0 25px var(--gold-glow),0 0 50px var(--gold-glow)} }
@keyframes spin        { to{rotate(360deg)} }
@keyframes float       { 0%,100%{translateY(0)} 50%{translateY(-6px)} }
@keyframes shine       { 0%{bg-position:-200% center} 100%{bg-position:200% center} }
@keyframes glow-text   { 0%,100%{text-shadow:0 0 10px var(--gold-glow)} 50%{text-shadow:0 0 20px var(--gold-glow),0 0 30px var(--gold-glow)} }
@keyframes slide-up    { from{translateY(100%);opacity:0} to{translateY(0);opacity:1} }
@keyframes fade-in     { from{opacity:0} to{opacity:1} }
@keyframes scale-in    { from{scale(0.8);opacity:0} to{scale(1);opacity:1} }
```

### 8.2 动画使用场景

| 动画类 | 效果 | 使用场景 |
|--------|------|----------|
| `.anim-pulse-glow` | 脉冲发光 | VIP卡片、限定活动入口 |
| `.anim-float` | 上下浮动 | 引导页插图、奖励图标 |
| `.anim-glow-text` | 文字发光 | 特殊标题、稀有奖励文字 |
| `.anim-spin` | 旋转 | 加载Spinner、转盘 |
| `.anim-slide-up` | 从底部滑入 | Toast |
| `.anim-fade-in` | 淡入 | 弹窗遮罩 |
| `.anim-scale-in` | 缩放进入 | 弹窗内容 |
