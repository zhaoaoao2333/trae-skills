## 二、子Agent职能一览

| Agent | 角色定位 | 核心职能 | 触发时机 | 文件路径 |
|-------|---------|---------|---------|---------|
| 督查Agent | 流程监督者 | 全程跟随，预防检查（行动前）+复盘检查（行动后），违规分级中断 | 项目启动到收尾全程 | `01-Agent定义/督查Agent.md` |
| 设计师Agent | 资深UE设计师（原型阶段项目经理） | 主导设计纲要生成、三层审查、收到反馈先判定再输出修改方案 | 阶段六步骤6.4起 | `01-Agent定义/设计师Agent.md` |
| 设计分析师Agent | 设计审查+规则提炼 | 原型生成前审查设计纲要/框架；原型生成后提炼可复用规则 | 阶段六步骤6.4/6.5后 + 阶段七 | `01-Agent定义/设计分析师Agent.md` |
| 验收员Agent | 产品测试专家（用户视角） | 以真实用户视角测试原型，7维度+规范冲突检查，输出结构化测试报告 | 阶段六步骤6.10 + 手动触发 | `01-Agent定义/验收员Agent.md` |
| 思维导图Agent | 结构化梳理工具 | 将需求/功能清单/PRD输出为逻辑清晰的思维导图 | 阶段三/手动触发（/mindmap） | `01-Agent定义/思维导图Agent.md` |
| 流程图Agent | 业务流程可视化工具 | 输出Mermaid格式流程图（多角色用泳道图） | 阶段三/手动触发（/flowchart） | `01-Agent定义/流程图Agent.md` |

### Agent协作关系

```
PM（决策） → 主Agent（调度+审核）
                ├─ 督查Agent（全程监督）
                ├─ 思维导图Agent（阶段三，可选先行）
                ├─ 流程图Agent（阶段三，可选先行）
                ├─ 设计师Agent（阶段六，主导设计纲要+审查）
                │    ├─ 设计分析师Agent（审查+规则提炼）
                │    └─ 验收员Agent（用户视角测试）
                └─ AI执行（文档/代码产出）
```

## 六、快速决策树

> 主Agent根据PM需求，按此树快速路由到对应阶段和文件。

```
PM需求
├─ "新项目" → 阶段一（项目启动）
│   └─ 加载：项目资产管理.md
│
├─ "梳理需求/功能清单" → 阶段三（需求梳理）
│   ├─ 加载：需求梳理技能.md、待确认问题清单模板.md、需求检查清单.md
│   ├─ 如需思维导图先行 → 调用思维导图Agent → 加载：思维导图生成规范.md、思维导图模板.md
│   └─ 如需流程图先行 → 调用流程图Agent → 加载：流程图生成规范.md、流程图模板.md
│
├─ "写PRD" → 阶段五（PRD产出）
│   └─ 加载：PRD编写规范.md、优先级规则.md
│
├─ "生成原型" → 阶段六（原型生成）
│   ├─ 前置检查：思维导图是否已完成
│   ├─ 步骤6.0：规范方向确认（检查多套规范冲突）
│   ├─ 步骤6.1-6.3：页面风格+导航+结构确认
│   ├─ 步骤6.3.5：分批生成策略（>20页时）
│   ├─ 步骤6.4：设计师Agent生成设计纲要
│   │   └─ 加载：设计纲要模板.md（海外游戏→海外游戏设计纲要模板.md）
│   ├─ 步骤6.5-6.9：框架设计+逐级闭环生成
│   │   └─ 加载：原型生成规范.md、原型样式规范.md、前端设计规则.md、组件库.md、行业模板库.md、设计模式库.md
│   ├─ 步骤6.10：设计师走查 + 验收员测试
│   ├─ 步骤6.11：全链路校验
│   └─ 步骤6.12：PM终审
│
├─ "测试原型" → 调用验收员Agent
│   └─ 加载：验收员Agent.md（7维度+规范冲突检查）
│
├─ "项目收尾/复盘" → 阶段七
│   ├─ 调用设计分析师Agent提炼规则
│   └─ 加载：案例库沉淀机制.md
│
└─ 行业判断 → 追加加载
    ├─ 游戏项目 → 行业特定规则.md（游戏章节）
    ├─ 海外项目 → 海外项目设计规范.md
    ├─ 海外游戏项目 → 两者叠加 + 海外游戏设计纲要模板.md
    └─ 有AI化需求 → AI化评估模板.md
```

| 阶段 | 名称 | 核心目标 | 关键输出 | PM确认点 |

## 维护规则

1. **每次补丁更新时同步更新本文件**：新增/修改规则、模板、模式后，同步更新对应索引章节和版本记录
2. **索引不展开细节**：本文件是索引不是文档，每项只写一句话摘要，详细信息在对应文件中
3. **快速决策树保持最新**：新增阶段或步骤时，同步更新决策树
4. **版本记录连续**：每次更新追加一行，不删除历史记录
